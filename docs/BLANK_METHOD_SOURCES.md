## 2. The invariant instruction set (identical on every workbook cover, S1–S4)

Printed verbatim across all levels and twenty years — this is the method's constitution:

1. "In each session, teach a single word," using all forms the child has learned (e.g., *hop, hopping, hops*).
2. "Teach only the words your child does not already know."
3. Follow the page directions exactly.
4. Keep a blank index card to **cover** words when instructed (retrieval, never copying).
5. "Immediately correct errors, saying, 'No, that is not right,'" then: reading errors → say the correct word, child repeats; writing errors → show the correct model, child redoes.
6. 4–6 sessions per week, 20–30 minutes each.
7. When the workbook's words are completed → go to Book N (connected reading).

Implications: the session unit is **one word-family**; the pretest is **per word**; errors are **never left standing**; every level ends in **reading connected text built from taught vocabulary**.

## 3. Per-word format catalog (the trial ladder)

Each word gets a fixed multi-format spread. Formats observed, with mechanics described:

| Format | Mechanic | Skill target | Notes |
|---|---|---|---|
| **Is It Known?** | Dictate the word unseen; child WRITES it. Perfect spelling → skip the word entirely, go to next | Placement (production bar) | The skip-chain also encodes teaching order (§5) |
| **Model + cover** | "This is X" while pointing; then cover the word; all later work is from memory | Modeling → retrieval | Opens every teaching sequence |
| **Savvy Sounds** | Target anchored to a partial form (e.g., "ki" = kid without d); find target among near-neighbors (kid/kiss/kick/kiln); includes form-vs-form (hop vs hopping) | Sounds + sequencing (discrimination, NOT blending) | Distractor tightness scales with level (S4: them/then/there/this/that/than) |
| **Word Scanner** | Find every instance of target in mixed rows, left-to-right; case variants included (my/My) | Visual scanning, sequencing | |
| **Spot 'n Sort** | Reverse task: cross out every word that is NOT the target | Discrimination | |
| **Detect 'n Select** | Find/circle every instance of the target inside real connected paragraphs; child does NOT read the other words aloud | Reading in context | |
| **Pick the Picture** | Content words only: match word to picture — response is WRITING the word under the picture | Meaning + writing | Non-content words never get this format |
| **Find 'n Fill / Letter In** | Complete missing letters to form the target; rows include dead frames that CANNOT become it (d_ns can't become need) | Orthographic production | Forces analysis before filling |
| **Write In To Read** | Write the target into sentence frames, then read the whole thing aloud | Sentence use + writing | Primary meaning format for non-content words |
| **Replace the Space** | Cloze: fill sentence blanks from a word bank | Sentence use | |
| **Symbol Search / Cipher Wiz** | Symbols/numbers map to words/phrases; child assembles and writes full sentences | Grammar + sequencing | Sentence-construction skill |
| **Stay 'n Play** | Cross out dotted intruder words to recover a grammatical sentence; then write it from dictation | Grammaticality judgment | |
| **Dictation-with-redo** | Woven through most formats: cover everything, dictate word by word; ANY error (incl. capitals & punctuation) → stop, show, cover, fresh paper, **redo from the first word** | Writing mastery | The wrong form is never the last thing practiced |
| **Progress Check** | End of level: dictated sentences, hard-scored (word correct only if spelling AND capitalization perfect); e.g., S2: ≥19/24 → advance to next level, ≤18 → review track. "Do not offer any assistance." | Gating | Measurement is unassisted; teaching is corrected |

Sequence shape per word: pretest → model+cover → discrimination → meaning → orthographic production → sentence use, with writing throughout. Roughly 30–45 child responses per word per session.

**Non-content-word variant:** skips Pick the Picture; gets extra sentence-frame work. Intro pages define non-content words as "words that combine to form sentences" — their meaning is combinatorial, so they are always taught in sentence context.

## 4. Reading Kingdom digital structure (S5)

- **Six skills:** sequencing, motor (keyboarding/writing), sounds, meaning, grammar, comprehension. Positioning: phonics covers ~2, whole language ~2, RK all 6.
- **Anti-phonics rationale:** most English words can't be sounded out; phonics needs ~600 exception-riddled rules; national ~40% reading-failure rate cited.
- **Skills Survey (placement):** keyboarding check (type shown letters/words) → sequencing check (select symbols matching a sample, left-to-right) → if either prerequisite is missing, the survey ENDS and teaching starts there (Letter Land for keyboarding; Seeing Sequences for sequencing) → otherwise continues into reading AND writing of words and sentences. Customization pitch: never bored by known material, never frustrated by too-advanced material.
- **Digital word-lesson formats observed:** hear "kid" → select among kid/kids/kin/king; hear "walk" → select which partial frame can become it (w__k vs p_l_ vs b__n vs wa__e); hear "bird" → pick the picture → then TYPE the word (model shown, graduating); leveled books including fill-in-the-word books; story comprehension in the program's second half.
- **Progress monitoring:** "not move ahead unless the learning is solid and secure." Regular Progress Checks; doing well → new material; weakness → dedicated review lessons for 1–2 weeks, then return to new material.

- Content: need/needs, wing/wings, hop/hopping/hops, use/using/uses, stop/stopping/stops

**S4 · Liftoff Workbook 16** — order (partial from extraction): them → hole(s) → find/finding/finds → out → be → … (full set:)
- Content: hole/holes, find/finding/finds, push/pushed/pushes/pushing, mice, get/getting/gets
- Non-content: them, out, be, us, then

**Cross-book observations (load-bearing for our redesign):**
1. **Interleaving:** content and non-content words alternate within a book (kid, girl, kids, girls, *some*, *a*, boy, *more*) — function words are not batched separately.
2. **Word families are the curriculum unit** — a "word" is defined WITH its forms (find, finding, finds), and forms are discriminated against each other in Savvy Sounds.
3. **Compositional review:** carrier sentences and Detect 'n Select passages are built (almost) entirely from previously taught vocabulary — every new-word session silently reviews old words.
4. **Classification pattern:** nouns/verbs/adjectives = content; pronouns, articles, quantifiers (some, more, all), preps/particles (out), copula (be), temporal connectives (then) = non-content. This corroborates our words-table tagging methodology.
5. **Coverage:** 4 workbooks of an estimated 16+ = PARTIAL inventory. Full reconciliation requires the complete set or Marion's master list.

**Known deltas vs our `words` table (inputs to CURRICULUM_RECON_R1 — do NOT edit the table from this doc):** her non-content words *them, us, be, out* are absent from our 45-function set; her content words *doll, rocket, wing, hole, mice* (and likely others) appear absent from our 200. Teaching ORDER has never been compared at all.

## 6. Assessment & correction doctrine (drives Placement v2 + Check-In v2)

1. **Measurement is unassisted.** Pretests and Progress Checks give no help ("Do not offer any assistance"); child moves on if stuck. → Matches our §5a placement rule; extends to all measurement surfaces.
2. **The bar is production.** "Known" = written/typed correctly, not recognized. Progress Check scores spelling + capitalization exactly.
3. **Prerequisite skills are gated first.** RK's survey checks sequencing and motor BEFORE word items, and routes to skill-building if absent.
4. **Results branch.** Pass → advance; weak → prescribed review period, then return. Never "not move ahead unless the learning is solid and secure."
5. **Teaching is the opposite of measurement:** every error immediately corrected, correct response performed by the child, redo from the start on written work.
