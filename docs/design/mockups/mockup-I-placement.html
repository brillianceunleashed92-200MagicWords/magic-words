Word probe · production

Build cat
The contract split that makes placement honest: teaching-mode Build It bounces wrong tiles back (errorless). Measurement-mode Build It places every tile you tap, in order, no judgment — try building it wrong. Three tiles in, Nova says "Ooh, next!" either way. This is Blank's "write cat" pretest, tablet-native. Production evidence, not tap-recognition.
